▦ Grid View (default)

มุมมองหลัก — repo card แต่ละใบ พร้อม mini heatmap 13 สัปดาห์ + sparkline การเติบโต + ปุ่ม action 6 ปุ่ม

📸 Grid view — repo cards 60 ใบ พร้อม mini heatmap + tags + live badges

โครงสร้าง Repo Card

  1. Header — emoji + ชื่อ repo + category chip + "LIVE" badge (ถ้า deploy แล้ว)
  2. Tags — คลิกได้, ใช้ filter (เช่น 3d · game · html · live)
  3. Description — คำอธิบายสั้น (desc)
  4. Mini heatmap — 13 weeks × 7 days (commits per day)
  5. Sparkline — กราฟเส้นการเติบโตของ stars
  6. Meta — size · lang · created date
  7. Click card → เปิด modal พร้อม actions 6 ปุ่ม
💡 Tip

คลิก tag เพื่อ filter ทันที · Shift+click tag เพื่อเพิ่ม combo (สูงสุด 3 tags)

💡 Tips & Tricks

🔍 Search + Filter

ใช้ tag filter + text search + sort ร่วมกัน — เช่น filter "live" + search "game" → เห็นแค่ games ที่ deploy แล้ว

📱 PWA Install

เปิดเมนู browser → "Add to Home Screen" เพื่อ install เป็น app — ใช้ได้แบบ offline

⚠️ GitHub Rate Limit

Calendar view เรียก GitHub API ตรง — จำกัด 60 req/hr ต่อ IP มี in-memory cache 2 นาที

🔥 Backups

Backend cache database เก็บที่ /opt/sj88-mission-control/data/cache.db — backup เป็น cron job
